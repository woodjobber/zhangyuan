校准公式与分层口径（默认内置 · 与校准卡V3.7一致）

校准得分率 = 卷面得分率 −（本校均分率 − 常模池基准P）
≥75% → 拔高冲刺层（75%~78% 为拔高下沿缓冲带，追踪3次） 72%~75% → 临界观察 <72% → 基础巩固层
四层台阶：筑基<60% 巩固60~70% 拓展70~80% 拔高≥80%
⛔ 铁律：基础题应得率（基础题实得÷基础题满分）<85% 时，无论总分多高，强制降为基础巩固层并标「待复核」。

各卷制划线（零平移速查值）

划线 = ceil(比例×满分)。本校均分偏离基准超过3个百分点时，以工具精算结果为准，勿直接套划线。

常模池（比较群体）取数规则

考试类型取哪个池为什么
本校平日卷 / 月考本校同年级本次均分÷满分（实测）高一高二无区域统考，本校年级是唯一可靠参照
成都各区中考/诊断分区取值，不跨区各区命题难度不同
四川高考数学分物理类/历史类，语文物理类/历史类分列两类分开投档，是两个独立竞争群体
高三一诊/二诊/三诊按届次、物理类/历史类分列（数学）同届三次难度差最大约0.07

范围—锚点匹配规则（防"用全卷锚校半卷考"）

考试范围推荐比较群体(锚)可否套全卷常模锚
章节考 / 月考本校同年级本次均分（自锚）不可，须自锚
期中考试（半册）本校同年级本次均分（自锚）不可，须自锚
期末（整册）/ 诊断模考 / 中高考对应区·对应科·对应科类常模池可（范围一致）
校准得分率 = 卷面得分率 −（本校均分率 − 常模池基准P）。教材、进度、群体等共模因子，只要常模池与本次考试同教材、同范围、同群体就自动抵消；错配（半卷套全卷锚、成都北师大版数学套德阳人教锚、实验班均分套全年级池）才变成系统偏差。精度重心在选对比较池与范围，不是改 75% 这条线。

科学性优化项（v7.2）

因子处理方式
学期 / 教学进度年级×上下学期 → 教材册次上限；补短只在已学知识点配题，未学册次灰显暂缓，不超纲

考试范围 / 卷型新增范围选择；半卷考套全卷锚时警告并引导自锚
评分宽严（主观题）语文/英语标"评分宽严敏感"，建议以本校历次均分纵向自比
